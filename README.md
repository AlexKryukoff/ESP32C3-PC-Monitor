# ESP32C3-PC-Monitor

ESP32-C3 + TFT-дисплей (ST7789, 2.4", 240x320) — панель мониторинга ПК в реальном времени: температура и загрузка CPU/GPU, использование RAM, температуры SSD, температура/индикатор вентилятора БП, графики FPS и Ping. Данные передаются по Serial (USB) от программы **MSI Afterburner Data Server (MADS)**.

## Источник данных (MADS)

Данные с ПК читает и пересылает по COM-порту сторонняя программа **MSI Afterburner Data Server (MADS)**, взятая с форума AlexGyver:
[https://community.alexgyver.ru/threads/msi-afterburner-data-server.3246/](https://community.alexgyver.ru/threads/msi-afterburner-data-server.3246/)

Программа и все права на неё принадлежат её автору с форума AlexGyver — в этом репозитории она используется как готовый инструмент для получения данных из MSI Afterburner, а не как собственная разработка. Скачивайте актуальную версию по ссылке выше.

## Возможности

- Два больших кольца: температура + загрузка CPU и GPU, с цветовым градиентом (синий → зелёный → жёлтый → красный)
- Три мини-кольца: SSD1, SSD2 (температуры), RAM (использовано, ГБ)
- Мини-кольцо блока питания: температура БП + индикатор работы вентилятора (загорается красным на полных оборотах)
- Графики FPS и Ping внизу экрана с автомасштабированием и динамическим цветом (зелёный/жёлтый/красный)
- Заставка (анимация шарика по кругу), пока данных с ПК нет
- Вентилятор блока питания ПК: отключён от штатного управления блока питания и подключён к плате через MOSFET, которым управляет ESP32-C3 по показаниям датчика температуры DS18B20 (измеряет температуру самого блока питания)

## Подключение дисплея (пины)

| Пин | GPIO |
|---|---|
| TFT_MISO | -1 (не используется) |
| TFT_MOSI | 20 |
| TFT_SCLK | 21 |
| TFT_CS | 10 |
| TFT_DC | 6 |
| TFT_RST | 7 |

Драйвер: `ST7789_DRIVER`, разрешение 240×320, цветовой порядок BGR.

Файл конфигурации: [`TFT_eSPI_Setups/Setup24_ST7789_ESP32.h`](./TFT_eSPI_Setups/Setup24_ST7789_ESP32.h)

### Прочие пины

| Пин | GPIO | Назначение |
|---|---|---|
| TEMP_PIN | 4 | Датчик температуры DS18B20 (OneWire) — измеряет температуру блока питания ПК |
| FAN_PIN | 5 | ШИМ-выход на MOSFET, управляющий вентилятором блока питания ПК |

## Установка библиотеки TFT_eSPI

1. Установите библиотеку **TFT_eSPI** через Arduino Library Manager.
2. Скачайте папку `TFT_eSPI_Setups` из этого репозитория и положите её **рядом** с папкой `TFT_eSPI` в директории `libraries` (не внутри неё):
   ```
   libraries/
   ├── TFT_eSPI/
   └── TFT_eSPI_Setups/
       └── Setup24_ST7789_ESP32.h
   ```
3. Откройте `TFT_eSPI/User_Setup_Select.h` и замените дефолтную строку подключения:
   ```cpp
   //#include <User_Setup.h>           // Default setup is root library folder
   #include <../TFT_eSPI_Setups/Setup24_ST7789_ESP32.h>
   ```

## Протокол данных (MADS → ESP32-C3)

MADS отправляет по Serial (9600 бод) 12 числовых значений через `;` в одной строке. Порядок значений задаётся файлом конфигурации [`MADS/Default.madsts`](./MADS/Default.madsts), уже включённым в репозиторий.

| # | Значение из MADS | Отображается на экране |
|---|---|---|
| 0 | CPU temperature | Большое кольцо CPU |
| 1 | GPU temperature | Большое кольцо GPU |
| 2 | CPU usage | Загрузка CPU (внутреннее кольцо) |
| 3 | GPU usage | Загрузка GPU (внутреннее кольцо) |
| 4 | CPU clock | ⚠️ Принимается, но не выводится (см. «Конструктор») |
| 5 | Ping | График Ping |
| 6 | Memory clock | ⚠️ Принимается, но не выводится |
| 7 | RAM usage (МБ, делится на 1000 в MADS) | Мини-кольцо RAM (ГБ) |
| 8 | Memory usage (%) | ⚠️ Принимается, но не выводится |
| 9 | HDD2 temperature | Мини-кольцо SSD2 |
| 10 | Framerate (FPS) | График FPS |
| 11 | HDD1 temperature 2 | Мини-кольцо SSD1 |

## Настройка MADS на ПК

1. Скачайте MADS по ссылке из раздела «Источник данных» выше.
2. В программе MADS импортируйте файл конфигурации [`MADS/Default.madsts`](./MADS/Default.madsts) из этого репозитория — он уже настраивает нужный порядок и формат всех 12 параметров.
3. Выберите COM-порт, на котором видна плата ESP32-C3, скорость **9600 бод**.
4. Запустите передачу данных — на экране платы появится живая панель мониторинга.

## Конструктор: что можно донастроить

- **CPU clock / Memory clock / Memory usage не выводятся.** MADS уже присылает эти три значения (индексы 4, 6, 8 в массиве `value[]`), но в коде `DrawDisplay()` они нигде не используются. Чтобы вывести их на экран, добавьте своё мини-кольцо или текстовое поле по аналогии с уже существующими (`drawMiniSSD`, `drawMiniRAM`, `drawMiniPSU`), взяв данные из `value[4]`, `value[6]`, `value[8]`.
- **Вентилятор блока питания включается/выключается резко.** Сейчас в `sensorsrequestTemperatures()` вентилятор либо выключен (0), либо на полную мощность (255) — при переходе через 43°C/55°C. Константы `TEMP_MIN` (35.0), `TEMP_MAX` (55.0), `DUTY_MIN` (180), `DUTY_MAX` (255) уже объявлены в начале файла, но не используются в этой логике. Чтобы сделать плавную ШИМ-регулировку оборотов, замените жёсткие пороги 43.0/55.0 на `map()`-интерполяцию между `TEMP_MIN`/`TEMP_MAX` → `DUTY_MIN`/`DUTY_MAX`.
- **Неиспользуемые заготовки в коде.** Спрайт `list` (задуман «для полосок внизу»), функция генератора шума `rng()` и массивы для звёздного неба (`sx`, `sy`, `sz`, `NSTARS`) объявлены в начале файла, но нигде не вызываются — похоже, остались от экспериментов с другим вариантом анимации заставки. Можно смело удалить эти строки или доработать под собственную анимацию.

## Примечание

Скетч не использует Wi-Fi — вся связь с ПК идёт по проводному USB/Serial соединению, никаких сетевых учётных данных в коде нет.
